## Overview
Engineered custom integrations and workflows focusing on AI agents and the Model Context Protocol (MCP). The project involves configuring OpenClaw automations and connecting various AI tools to create robust, automated workflows. This includes leveraging RAG, local LLMs, and commercial APIs (OpenAI, Gemini, Anthropic) backed by FastAPI and MongoDB.

## Responsibilities
- Configure OpenClaw skills, heartbeat workflows, and integrations (Telegram, email).
- Develop custom MCP connections for external tools, such as integrating Blender for 3D modeling workflows.
- Build AI-assisted workflows utilizing RAG and various LLM APIs.
- Set up backend infrastructure using FastAPI and MongoDB to support AI integrations.

## Results
- Established a versatile framework for AI agent interactions and tool use.
- Successfully connected disparate tools and APIs into cohesive, automated workflows.
- Enhanced capabilities for processing and acting upon information using advanced AI models.
